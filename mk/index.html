数据来源与计算口径

利率：FEDFUNDS 月均有效利率。国债：GS2 / GS10 月均收益率，非债券价格。非农：PAYEMS 季调就业总量的月度差值，单位千人。

GDP：GDPC1 实际 GDP 季环比年化增速；快照同时展示 GDP 名义总量（年率）。Nasdaq 为综合指数 ^IXIC，标普为 ^GSPC；QQQ 为 ETF。Yahoo Finance 日收盘聚合为月末值；不计现金分红，不代表总回报。

更新、历史保存与数据状态

GitHub Actions 每小时抓取一次，并保存完整历史文件；网页每分钟检查新版本。不是逐笔或分钟行情。当前月份使用最新已取得的常规交易时段报价（可能有延迟），没有可用报价时使用已完成交易日收盘，标记为“月内暂值”。任务可能延迟；抓取失败保留旧值并显示状态。源接口可能限流，Yahoo 接口无可用性保证。
